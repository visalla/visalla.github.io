Política de Privacidade

Última atualização: 28 de outubro de 2026

Esta política explica como o PGTA6 ("aplicativo") trata os dados acessados por meio da sua Conta do Google e dos Serviços de API do YouTube, e por meio da sua conta do TikTok.

O PGTA6 usa os Serviços de API do YouTube. Ao usar o aplicativo, você também concorda com os Termos de Serviço do YouTube, e os dados tratados pelo Google seguem a Política de Privacidade do Google.

Dados acessados

Quando um canal de cortes é conectado, o aplicativo pede permissão para:

  • Enviar vídeos (youtube.upload) ao canal conectado;
  • Ler informações do canal (youtube.readonly), como nome, ID e número de inscritos;
  • Ler métricas do YouTube Analytics (yt-analytics.readonly), como visualizações e retenção dos vídeos publicados.

O aplicativo também consulta dados públicos do YouTube, como títulos, estatísticas e comentários públicos de vídeos.

Dados acessados no TikTok

Quando uma conta do TikTok é conectada (login pelo TikTok, com o Login Kit), o aplicativo pede permissão para:

  • Ler informações básicas do perfil (user.info.basic), como o nome de exibição e o identificador da conta;
  • Enviar vídeos como rascunho (video.upload) para a caixa de entrada da conta. O próprio usuário revisa, escreve a legenda e publica no aplicativo do TikTok.

O uso desses dados segue também os Termos de Serviço e a Política de Privacidade do TikTok.

Como os dados são usados

Os dados são usados só para operar o aplicativo: publicar os cortes aprovados, identificar o canal conectado e medir o desempenho dos cortes para melhorar as próximas escolhas. Não vendemos dados, não usamos dados para publicidade e não os compartilhamos com terceiros, exceto quando a lei exigir.

Armazenamento

Os tokens de acesso e os dados obtidos ficam guardados apenas localmente, no computador onde o aplicativo é executado. Não há servidor próprio que armazene esses dados. Para escolher os trechos dos vídeos, transcrições de vídeos públicos podem ser processadas pelo serviço de IA da Anthropic (Claude), sem envio de tokens de acesso ou de dados privados das contas.

Retenção e exclusão

Os dados ficam guardados enquanto o canal estiver conectado. Para remover o acesso do TikTok, use "Desconectar" no aplicativo ou remova o PGTA6 em Configurações e privacidade > Segurança > Apps e serviços no TikTok. Para remover o acesso do Google a qualquer momento, desconecte o aplicativo na página de permissões da sua Conta do Google. Você também pode pedir a exclusão dos dados locais pelo e-mail abaixo; o pedido é atendido em até 7 dias. Dados obtidos da API do YouTube que não forem atualizados são apagados em até 30 dias.
